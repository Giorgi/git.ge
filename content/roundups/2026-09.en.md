In September, git.ge developers created 22 new repositories with at least 3 stars. Several of the new projects are tools for working with AI coding agents (Sloppy, Stvena, fast-compact, RetroPair), and two are plugins for Omarchy. Ten listed projects published a release, including Musify, driftwm and sury.

## New this month

The most popular repositories created in September 2026, by stars as of 2026-10-22.

### [tornikegomareli/omarchy-spaces](https://github.com/tornikegomareli/omarchy-spaces)

★ 203 · JavaScript · created 2026-09-25

> See what runs on every workspace. An Omarchy bar widget that shows the apps open on each workspace.

Spaces is a workspace switcher for the Omarchy bar: each workspace shows the icons of the apps open on it, and hovering another one opens a live preview. Terminals running Claude Code, OpenCode or Cursor get a badge showing whether the agent is working, waiting for you or done.

### [Pronexsteam/deviload](https://github.com/Pronexsteam/deviload)

★ 174 · JavaScript · created 2026-09-15

> Deviload — a clean Windows desktop front-end for yt-lp: paste a link, pick quality, download. Playlists,chapters, trim, GIF, one-click YouTube sign-in, RU/E.

Deviload is a desktop app built with Rust and Tauri 2 for listening to music, downloading video and audio with yt-dlp, and cutting clips. Windows is the main target, with Linux packages too; the interface is in English, Russian and Spanish.

### [Heyosseus/sloppy](https://github.com/Heyosseus/sloppy)

★ 161 · PHP · created 2026-09-10

> Static analysis for the debt AI agents leave in PHP: 33 rules, Claude Code hooks, git-diff review, a Rector and Pint fix pass, Pest expectations, CI annotations and an MCP server. Deterministic, local, no LLM.

Sloppy is a static analyser for PHP that looks for the mistakes AI agents tend to leave: swallowed exceptions, oversized methods, N+1 queries. In Claude Code it runs after every edit and hands new findings straight back to the agent; it works locally, with no model or API key.

### [themidnightgospel/Rustaveli.Pdf](https://github.com/themidnightgospel/Rustaveli.Pdf)

★ 24 · C# · created 2026-09-26

> A free, open source, fluent PDF generation library for .NET.

Rustaveli.Pdf is a .NET library for building PDF files in code. It is MIT-licensed and supports tables that span pages, both text directions, PDF/A and PDF/UA, encryption and merging.

### [JWo1F/icofon](https://github.com/JWo1F/icofon)

★ 13 · Rust · created 2026-09-01

> Build an icon font and matching stylesheet from a folder of SVG files.

icofon turns a folder of SVG files into an icon font in woff2, woff and ttf, with a CSS class per icon and a searchable preview page. It is written in Rust; its check command is meant for CI and fails on any icon that can't become a glyph.

### [nccapo/stvena](https://github.com/nccapo/stvena)

★ 10 · Go · created 2026-09-08

> Your coding agent. Your changes. One terminal. A live review workspace for Codex and Claude Code, built in Go.

Stvena opens a live review workspace in the terminal next to Codex or Claude Code, so you can go through the agent's changes without opening an IDE. You can select exact lines and send them back to the agent as context. The author notes it is early-stage software.

### [JWo1F/serv](https://github.com/JWo1F/serv)

★ 8 · Rust · created 2026-09-09

> A small dev server for static sites, single-page apps and markdown.

serv is a small server for running static sites, single-page apps and markdown locally: point it at a folder and open the URL. It needs no config file. It's the second Rust project by icofon's author on this list.

### [NodarDavituri/fast-compact](https://github.com/NodarDavituri/fast-compact)

★ 8 · TypeScript · created 2026-09-26

> /fc for Claude Code: shrink old tool output in about a second — Jev keeps what's still needed, every cut saved to a file. Your /compact stays untouched.

fast-compact is a Claude Code plugin whose /fc command frees context in about a second: it cuts old tool output down to its start and end and saves the full text to a file Claude can read back. The built-in /compact stays untouched.

### [Serg1kk/retropair](https://github.com/Serg1kk/retropair)

★ 6 · Python · created 2026-09-27

> Evidence-based coaching for developers working with AI coding agents. Review the pair. Improve the human.

RetroPair is a Claude Code plugin that reads your agent session logs and reviews not the code but how you lead the agent: how you frame tasks and verify results. It scores eight axes, backs each score with a verbatim quote from the log, and suggests one to three next steps.

### [asmyshlyaev177/omarchy-last-session](https://github.com/asmyshlyaev177/omarchy-last-session)

★ 5 · Python · created 2026-09-18

> Omarchy shell plugin that reopens your last session's windows after a reboot or logout, on the workspace and monitor they were on. Terminals return to their working directory, browsers keep their tabs. Snapshots on every window change, no manual step.

omarchy-last-session is an Omarchy plugin that brings back your open windows after a reboot, logout or crash, on the workspace and monitor they were on. It uses only the Python standard library and needs Hyprland 0.55 or newer.
