# Roundups

One Markdown file per roundup, named `YYYY-MM-<slug>.md`; the file name (without
`.md`) becomes the URL: `/roundups/<file name>/`. Start each file with:

```
---
title: სექტემბერი 2026
date: 2026-10-01
summary: One line, shown in the list and the RSS feed.
---
```

Raw HTML is disabled; use Markdown only. Roundups are written by hand and are not
switched by the English toggle, so write each one in the language you want it in.
This README is not published.
